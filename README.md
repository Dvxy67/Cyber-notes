# cyber-notes

Développeur web full-stack (Laravel, React/Vite, Node.js, Docker, WordPress) basé à Bruxelles, je me forme à la **cybersécurité défensive**, avec un objectif clair : le métier d'**analyste SOC / blue team**.

Ce repo n'est pas un carnet de réponses. C'est le journal de ma progression : des notes rédigées avec mes propres mots, organisées par thème, et des cheatsheets que j'utilise réellement.

> Prochaine étape : formation **Cybersecurity Analyst** (Bruxelles Formation × Digitalcity.brussels), janvier → juillet 2027.
